- CPM agregado BR: US$1,14 / RPM US$0,58 = ~**R$3,07 / 1000 views** (mais conservador) ([Lenostube](https://lenostube.com/en/youtube-cpm-rpm-rates/))
- Shorts BR: **R$0,10-1,50 / 1000 views** (muito baixo) ([FluxNote](https://fluxnote.io/guides/youtube-shorts-rpm-brazil-2026))

### Nichos com RPM documentado (OutlierKit — valores tendem a ser globais, BR aplica ajuste)

Gospel/religioso, música instrumental, meditação guiada, dark history, fatos curiosos, contos infantis, astrologia/tarô, "top 10".

**Trabalhar com premissa conservadora**: assumir RPM BR ajustado = **30-50% do RPM global**. Para long-form:
- Gospel instrumental (nicho musical, Brasil tier-3, audiência ampla): **R$2-6 / 1000 views** (estimativa conservadora; validar nos primeiros 3 meses com AdSense real)

## 5. Gates matemáticos (critérios de aprovação)

**Quebra-mês-2** (receita mensal cobre ferramentas):
- Cenário A (R$108/mês): receita ≥ R$108 → break-even tool
- Cenário C (R$138/mês): receita ≥ R$138 → break-even tool

**ROI significativo mês 6** (vale o tempo 5-10h/semana):
- Receita ≥ **R$500/mês** por canal (equivalente a ~R$15/hora se 7h/semana × 4 semanas = 28h → R$500/28h = R$17,86/h, ainda baixo mas valida)
- Receita ≥ **R$1.500/mês** é onde vale a pena DE VERDADE (R$53/h)

**Views mínimas mês 6** (pra bater R$500):
- RPM R$5 → precisa **100k views/mês**
- RPM R$10 → precisa **50k views/mês**
- RPM R$20 (estoico) → precisa **25k views/mês**

**Com AdSense requer YPP**: 1000 subs + 4000h watchtime (long-form) OU 1000 subs + 10M views Shorts em 90d.
