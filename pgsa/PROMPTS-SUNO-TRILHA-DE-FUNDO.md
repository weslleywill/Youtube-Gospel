## 🔄 DIFERENCIAÇÃO MATINAL × NOTURNO

| Aspecto | **MATINAL** (Qua 12h, Qui 07h) | **NOTURNO** (maioria) |
|---|---|---|
| BPM | 65-75 | 50-60 |
| Chave musical | G maior / D maior (luminosa) | D menor / A menor (contemplativa) |
| Piano | Clean, staccato leve | Reverb longo, sustain pesado |
| Pads | Soft strings, flauta | Pads densos, cello |
| Ambiente | Passarinho distante, vento leve | Chuva, vela, silêncio |
| Referência sonora | Nívea Soares, Gabriela Rocha | Cícero Euclides, Som Das Teclas |

## 🛡️ POLICY SHIELD — Regras pra Suno Pro

**Suno Pro tem licença comercial** — você pode usar monetização. MAS:
1. NÃO usa nomes de artistas reais no prompt ("in style of Cicero Euclides" = OK descritor / "a song by Cicero" = NÃO)
2. Aplica **EQ −3dB em 12kHz** pós-master pra quebrar spectral watermark Suno (se existir)
3. Credita como **Gospel Pra Descansar** (seu nome de artista), não Suno
4. Para DistroKid distribuir, faz pós-processamento obrigatório (ver abaixo)

**Pós-master anti-detecção**:
```bash
ffmpeg -i suno-raw.mp3 \
  -af "loudnorm=I=-14:TP=-1:LRA=7, equalizer=f=12000:t=h:width=2000:g=-3" \
  -b:a 192k output-mastered.mp3
```

## 📊 METAS DE QUALIDADE SONORA (ebur128)

- **Loudness I**: −14 LUFS (padrão streaming)
- **True Peak**: ≤ −1 dBTP
- **LRA**: < 6 LU (sleep music precisa ser consistente, não dinâmico)
- **Stereo width**: 0.7-0.9 (imersivo mas mono-compatible)

Validar cada faixa final com:
```bash
ffmpeg -i faixa.mp3 -filter:a ebur128 -f null -
```
