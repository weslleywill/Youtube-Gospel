## V1 — Max Lucro M2 🏆 R$676/mês

### Quando escolher
- Quer maior lucro líquido em R$ no mês 2 possível dentro das constraints originais
- Aceita usar lead magnet (isca) + IG pessoal como canais
- Tem 5-6h/sem disponíveis sem 1 pra setup

### Números-chave
| Métrica | Valor |
|---|---|
| Lucro líquido M2 | **R$676** (baseline) |
| ROI M2 | +169% |
| 1ª venda | dia 2 (tripwire) |
| Setup cost | R$400 Meta + R$50 Amazon |
| Tempo sem 1 | 6-7h (pico) |
| Tempo sem 2+ | 4h/sem |
| Stress pass | 4/4 |

### Setup semana 1 (6-7h spread)
1. Escrever checklist lead magnet PDF + mini-guia tripwire R$1 (1,5h)
2. Setup LP Carrd lead magnet + LP checkout tripwire R$1 Hotmart (1h) — **testar taxa Hotmart em R$1 antes; fallback R$5 ou R$9 se bloqueio**
3. Gravar 3 Reels ad (autênticos, celular, hook "não era pra dar certo") (1h)
4. Configurar Meta Ads CBO R$13/dia, Advantage+ fitness BR (30min)
5. Escrever 5 emails sequence (pós-tripwire = venda ebook R$37 + bump R$17 + bump R$27 + upsell R$67) (2h)
6. Formatar + publicar ebook Amazon KDP R$9,90 "Academia Sem Mentira" (1h)
7. Ativar skill `spy` + `repurpose` pra IG repurpose 3 Reels/sem (30min)

### Composição
- Meta Ads lead magnet R$400/mês → 38 leads
- Tripwire R$1 penny entry no email 2 (CVR 45% vs R$9 CVR 25%) → 17 compradores
- Email sequence 5 emails com pitch ebook R$37
- Ebook + bump R$17 + **bump R$27 duplo** + upsell R$67
- Amazon KDP ebook R$9,90 paralelo (R$280/mês)
- IG Repurpose via skills spy + repurpose (R$169/mês extra)

### Kill switches
- CPL Meta >R$25 após 7d → pausa, revisa hook via `spy`
- Tripwire R$1 CVR <35% após 50 leads → sobe pra R$5 ou R$9 (re-teste)
- Zero vendas até dia 21 → kill, investigar LP/copy
- Hotmart bloqueia R$1 → imediato fallback pra R$5 (CVR 30% esperado)

### Notas
- Mantém todo skeleton do #64 (ESTRATEGIA-VENCEDORA.md) só muda tripwire R$9→R$1 + adiciona 2º bump R$27
- **Risco técnico**: Hotmart taxa mínima pode inviabilizar R$1. Ter fallback pronto.

### Quando escolher
- Filosofia "sem isca agressiva" é inegociável
- IG pessoal é quebrado (1.254 seg, CVR 0,56%) e não quer investir nele
- Aceita 1ª venda borderline 30d
- OK usar R$250/mês em ads — **mas dentro da Amazon, não no Meta**

### Números-chave
| Métrica | Valor |
|---|---|
| Lucro líquido M2 | **R$443** |
| ROI M2 | +177% sobre R$250 |
| 1ª venda | dia 7-30 (afiliados dia 1-7 se propagar) |
| Setup cost | R$50 (capa Amazon) + R$200/mês Amazon Ads |
| Tempo sem 1 | 5h |
| Tempo sem 2+ | 2h/sem |
| Stress pass | 4/4 |

### Setup semana 1 (5h)
1. Escrever ebook Amazon R$9,90 "Academia Sem Mentira — 5 Verdades" (1h, via `copy` + `brand-voice`)
2. Formatar + capa Canva (1h, via anthropic-skills:docx)
3. Publicar Amazon KDP BR (30min)
4. Ativar programa afiliados Hotmart 60% + swipe copy (1h)
5. Configurar Amazon Advertising Sponsored Products, target ACoS 30% (1,5h)
6. Inscrever em **Kindle Unlimited** (KU) pra halo effect ranking

### Composição
- Amazon KDP ebook R$9,90 (orgânico + paid ads)
- Afiliados Hotmart 60% rede ativa

### Notas
- **Grande insight iter-05**: Amazon Ads ≠ Meta Ads cold. Audience dentro Amazon já tá pra comprar livros. Matematicamente fecha.
- Upgrade de V2 #94+98 do iter-04 (+R$139/mês vs baseline R$304)
- **Escalável**: cada R$1 Amazon Ads → R$3-4 retorno dentro ACoS target

## V3 — Velocity (1ª venda ≤3 dias) 🏆 R$370/mês

### Quando escolher
- Precisa da 1ª venda muito rápido (dia 1-3)
- Psicologia "preciso validar / não vou gastar sem provar"
- OK depender de humanos (afiliados, PTs) aceitarem
- Budget R$0 pra ads (só outreach)

### Números-chave
| Métrica | Valor |
|---|---|
| Lucro líquido M2 | R$370 |
| ROI M2 | infinito (custo R$0) |
| 1ª venda | **dia 1-3** (75% probabilidade) |
| Setup cost | **R$0** |
| Tempo sem 1 | 3h |
| Tempo sem 2+ | 1h/sem |
| Stress pass | 2/3 (depende humano) |

### Setup dia 1 (2-3h)
1. Ativar programa afiliados Hotmart 60% + página afiliados + swipe copy (30min)
2. Postar em 3+ grupos Telegram BR "afiliados Hotmart fitness" (30min) — buscar "afiliados hotmart" no Telegram
3. Outreach 5-10 PTs micro-influencers fitness BR (20-50k seg IG) com proposta co-op 50% split + bônus exclusivo compradores (2h DMs personalizados)

### Composição
- Afiliados Hotmart rede ativa (2 caminhos)
- Co-op 1-2 PTs com lista aquecida (split receita 50% + bônus pros compradores)
- Zero ads, zero setup técnico pesado

### Kill switches
- Se 0 afiliados + 0 PTs aceitarem em 7 dias → pivotar pra **V2 ou V4** (velocity falhou, aceitar ritmo orgânico)
- Afiliado propaga mas CVR <0,5% → revisar swipe copy + landing
- PT aceita mas não envia → follow-up no dia 4, dia 7, depois abandona

### Plano B (se V3 falhar em 7 dias)
- Pre-order R$19 founder em grupo WhatsApp BR fitness 10k+ (se Weslley conseguir acesso permissivo)
- Se não: pivotar direto pra V4 (hands-off) e aceitar Amazon M1-M2 maturation

### Notas
- Dependência total de terceiros é o risco estrutural
- **Outreach VOLUME resolve probabilidade**: 20 PTs > 5 PTs pra 1ª venda garantida
- Zero custo = zero downside financeiro

- Disponibilidade ≤1h/sem após setup é inegociável
- Prefere compound orgânico a growth ativo
- Não quer lidar com Meta Ads, hook fadiga, otimização semanal
- Visão longa: quer renda permanente sem tocar recorrente

### Números-chave
| Métrica | Valor |
|---|---|
| Lucro líquido M2 | R$400-500 |
| Lucro líquido M6 | **R$800-1.200/mês sustentável** |
| 1ª venda | dia 30-45 |
| Setup cost | R$150 (3 capas + formatação 3 ebooks) |
| Tempo setup | 9h total (spread em 3 semanas) |
| Tempo sem 2+ | **0,5h/sem** (monitorar BSR + reviews) |
| Stress pass | 2/3 |

### Setup semana 1-3 (9h spread)
- **Semana 1 (3h)**: Escrever + publicar Ebook 1 "Academia Sem Mentira — 5 Verdades" R$9,90
- **Semana 2 (3h)**: Escrever + publicar Ebook 2 "5 Mitos Que Me Travaram Na Academia" R$9,90
- **Semana 3 (3h)**: Escrever + publicar Ebook 3 "O Que Ninguém Conta Sobre TRT/Hormônio Natural" R$14,90

Todos via skill `copy` + `brand-voice:enforce-voice` + `anthropic-skills:docx`. Capa Canva, brand preto+laranja/âmbar.

### Composição
- 3 ebooks Amazon KDP com CTA final pro ebook principal Hotmart R$37
- Todos em Kindle Unlimited (halo effect ranking)
- Afiliados Hotmart 60% passivo (já ativo se veio de V2)
- ZERO ads recorrente

### Kill switches
- Ebook X <5 vendas dia 60 → revisar título/capa/keywords (prob SEO interno Amazon)
- Amazon kill 1 ebook → 2/3 receita sobrevive (diversificação estrutural)
- Review negativo abaixo de 3 estrelas em massa → revisar produto (crítica real vs troll)

### Insight-chave iter-05
- **V4 é estruturalmente sub-estimada**: trato como "plan B sem isca" nas iters anteriores, mas matematicamente ganha de V2 em lucro M6 (R$1.000+ vs R$800-900) SEM dependência de ads
- **Prescrição universal**: V4 deveria rodar **embaixo de V1/V2/V5** como camada permanente de diversificação estrutural

## 🧭 Decisão rápida (cheat sheet)

Responda honestamente:

**"Qual é sua prioridade NÚMERO UM?"**

- **"Lucro M2 máximo"** → V1
- **"Não usar isca nem meu IG"** → V2
- **"Provar que funciona dia 1-3"** → V3
- **"Mínimo esforço recorrente"** → V4
- **"Renda sustentável M6+"** → V5 (**default agent rec**)

**Combinações que fazem sentido**:
- V5 + V4 embaixo (recomendado default — V5 como engine + V4 como cimento)
- V1 + V4 embaixo (se Weslley quer M2 cash mas também fundação passive)
- V2 + V4 (se quer 100% sem Meta, fundação Amazon compondo)

**NÃO combine**:
- V1 + V2 (ticket overlap, confunde público)
- V3 + ads pagos (V3 é zero ads; misturar perde o ponto)
