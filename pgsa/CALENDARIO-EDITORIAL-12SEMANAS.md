## 🔄 Regras de otimização (aplicar a partir semana 4)

### A/B test de thumbnails
- YouTube permite 3 variantes — usar nos **4 piores performers** do mês
- Testar elementos: Bíblia+vela vs paisagem noturna vs piano dark
- Deixar rodar 7 dias → manter vencedor

### Rotação de keywords
- **NUNCA** usar exata mesma keyword 2 semanas seguidas (audiência percebe + algoritmo desprioriza)
- **Misturar** variações: "Pra Dormir" / "Pra Descansar" / "Pra Sono Profundo" / "Pra Insônia"

### Pinned comment — teste de 3 versões
- Semana 1-3: Versão A (direta)
- Semana 4-6: Versão B (história)
- Semana 7-9: Versão C (pergunta)
- Ver CVR de cada — manter vencedora
