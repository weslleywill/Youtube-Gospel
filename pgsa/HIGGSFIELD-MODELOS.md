## 🎯 Recomendações por caso de uso (canal gospel Weslley)

### Thumbnail de YouTube (imagem com texto grande)

1. **GPT Image 2** — DEFAULT. 4K + near-perfect text rendering. É o modelo que gerou a thumb "ELE OUVE" aprovada (via ChatGPT, mesma família).
2. **Nano Banana Pro** — alternativa se GPT Image 2 estilizar demais. Prompt adherence absurda.
3. **Higgsfield Soul Cinema** — se quer estética ainda mais "cinematográfica pintada".

### Thumbnail → vídeo loop 10s (image-to-video pro fundo)

1. **Kling 3.0 EXCLUSIVE** — DEFAULT. 4K nativo, 3-15s, aceita imagem direto (image-to-video), som desativável.
2. **Minimax Hailuo** — MAIS EM CONTA (oficialmente "fastest and most affordable"). Pra iterar barato ou quando créditos do Kling tão no limite.
3. **Seedance 2.0 Fast** — fallback 720p rápido.
4. ❌ **Kling 3.0 Motion Control** — NÃO serve: precisa de vídeo de input (motion transfer), não aceita imagem.

### Ilustração de capa de ebook

1. **Reve** — advanced image editing, estética pictórica.
2. **FLUX.2 Max** — precisão + velocidade.

### Cena cinematográfica sem texto (apenas visual épico)

1. **Higgsfield Soul Cinema** — feito pra isso.
2. **Seedream 4.5** — 4K cinematográfico.
3. **Nano Banana Pro** — sempre opção segura.

### Rosto/personagem consistente entre thumbs (futuro)

1. **Higgsfield Character Swap** — seamless character swap entre imagens.
2. **Higgsfield Face Swap** — só a face, composição fica livre.
3. **Multi Reference** — múltiplas imagens de referência numa geração.
