## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Kling Motion Control pra image-to-video | Motion Control exige vídeo de input, não aceita imagem pura | blocking | Ver thread `kling-motion-control-precisa-video-input` — usar Kling 3.0 EXCLUSIVE |
| Prompts de loop sem PALETTE/LOOP LOCK | "revealing brightness toward end" muda paleta e quebra loop | blocking | Ver thread `prompt-video-loop-palette-lock-frame-match` |
| Descrição pública mencionando "Suno Pro" | Algoritmo YouTube classifica como AI-generated → reduz monetização | blocking | Memory `feedback_descricao_sem_suno_disclaimer` |
| Modelo 2 de imagem = mesmo engine do ChatGPT | GPT Image 2 no Higgsfield = mesmo GPT-Image-2 (redundante) | blocking | Memory `feedback_modelo_2_sempre_diferente_e_economico` |
| Tags separadas por espaço | YouTube trata como 1 tag única bugada (90 chars) | blocking | Tags sempre separadas por VÍRGULA, hashtags só na descrição |
| Prompt Suno > 1000 chars | Suno trunca silenciosamente | advisory | Validar via `utils/count-prompt.py` antes de colar |
