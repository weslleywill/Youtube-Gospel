## 🌱 Como funciona

Cada seed é um arquivo `.md` com:
- Ideia em 1 parágrafo
- **Trigger de ativação**: condição que faz a ideia voltar à tona
- **Fase alvo**: em qual fase seria considerada
- **Data de criação**: pra saber idade

Formato: `nome-curto-da-ideia.md`
