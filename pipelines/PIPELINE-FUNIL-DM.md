# PIPELINE 06 — Funil DM (Conteúdo → Perfil → DM → Venda R$37)

> Pipeline 6 de 12 • O funil principal do Weslley hoje (fase 0 vendas). Conversão acontece em DM, não em landing page.

## Objetivo
Criar fluxo consistente: quem consome conteúdo → visita perfil → manda DM (dúvida, interesse, curiosidade) → conversa honesta → compra o ebook R$37 via Hotmart.

**Meta de conversão**: DM iniciada → venda fechada >= 3%.

## Quando disparar (gatilho)
- Setup inicial do funil (uma vez, documentar fluxo)
- DM chega no Weslley (resposta imediata em < 4h)
- Semanalmente: auditoria de DMs — quantas iniciaram, quantas converteram, onde perdeu
- Peça orgânica performou bem (esperar aumento no volume de DMs, preparar scripts)

## Inputs necessários
- **Perfil IG otimizado**: bio clara + destaques + foto profissional
- **Link bio**: landing page simples do ebook (não loja-mundão) + link IG carrossel pin
- **Scripts de DM aprovados** (este pipeline gera e mantém)
- **Oferta clara**: "O Treino Que Ninguém Vê" R$37, Hotmart, garantia 7 dias
- **WhatsApp MCP** (opcional mas recomendado): automatiza parte do processo

## Passo a passo

### Passo 1 — Skill `hundred-million-offers` (estruturar a oferta antes de tudo)
Se a oferta não tá clara na cabeça, nenhum script de DM salva.
```
/hundred-million-offers produto: ebook "O Treino Que Ninguém Vê",
preço: R$37, público: homem 20-35 iniciante academia,
estruturar: value equation (sonho/probabilidade/tempo/esforço),
bonus stack mínimo (sem ficar infoprodutor), garantia 7 dias devolução
```
**O que espero**: oferta escrita em 1 parágrafo que o Weslley consiga dizer no WhatsApp sem soar ensaiado.

**Exemplo**:
> "É um ebook de 28 páginas, tudo que eu queria ter sabido quando comecei — 12 erros que eu cometi + como corrigi. R$37. Se não servir, devolvo o dinheiro em 7 dias, sem drama."

### Passo 2 — Skill `copywriting` (bio + link bio + CTA cross-platform)
Bio é a primeira porta. Se a bio não converte "visitou → seguiu + clicou", o funil quebra aqui.
```
/copywriting formato: bio IG (150 caracteres),
tom: autenticidade radical, 1ª pessoa,
estrutura: quem sou + pra quem falo + CTA suave pro link,
link bio: 1 link principal (landing ebook) + link secundário (IG carrossel pin ou story destacado)
```
**O que espero**:
- Bio em 150 chars com clareza absoluta
- CTA de link bio conversacional ("link abaixo pro ebook que escrevi", não "CLIQUE AGORA")

### Passo 3 — Skill `marketing-psychology` (gatilhos em DM sem ficar escroto)
Identificar quais gatilhos usar na conversa sem perder tom de amigo.
```
/marketing-psychology contexto: conversa DM fitness,
objetivo: converter curiosidade em compra de R$37,
gatilhos ACEITÁVEIS: prova social (quantas pessoas já compraram), reciprocidade (dicas grátis antes da venda), autoridade vulnerável,
gatilhos BANIDOS: urgência fake, escassez inventada, loss aversion agressivo
```
**O que espero**: lista curta de 3-4 gatilhos que cabem no tom, com exemplo de uso em frase pronta.

### Passo 4 — Scripts de DM (criar templates respeitando TOM-DE-MARCA)

Scripts não são robóticos. São **ponto de partida** — o Weslley adapta pra pessoa. Mas sem script, cada DM vira improviso e perde consistência.

**Script A — DM proativo (quem salvou/comentou o post)**
```
"E aí, [nome]! Vi que você salvou o reel da remada.
Te falei lá que escrevi um ebook com os erros que eu fiz quando comecei —
é um resumo honesto, sem firula. R$37.
Se te interessar, te mando o link.
Mas não tem pressão, tá? Posso só te responder dúvida de treino também."
```

**Script B — Responder "qual link?" / "onde compro?"**
```
"Boa, [nome]! O link é esse aqui: [link Hotmart].
É o ebook que eu venho falando — os 12 erros que eu fiz nos primeiros meses
e como corrigi. Tem garantia de 7 dias, se não servir eu devolvo.
Qualquer dúvida depois, me chama aqui."
```

**Script C — Responder "vale a pena?"**
```
"Olha, [nome], vou te falar o que é e o que não é pra você decidir.
**É**: ebook curto (28 páginas), básico honesto, pra quem tá começando ou perdido.
**Não é**: método premium, plano de treino personalizado, milagre.
R$37 com garantia. Se você já treina há anos e já leu bastante,
talvez não seja pra você. Me conta em que pé você tá."
```

**Script D — Responder dúvida de treino (sem vender)**
```
"Opa, [nome], respondo aqui rapidão — [resposta real à dúvida].
Isso eu aprendi errando, inclusive ta no ebook que escrevi.
Mas a resposta direta é essa aí 👆. Qualquer coisa, me fala."
```
(Nota: o produto aparece como "inclusive" — não força. Se ele perguntar, responde. Se não, segue.)

**Script E — Objeção de preço**
```
"Entendo, [nome]. R$37 pode parecer pouco ou muito dependendo do momento.
Pensa assim: o ebook é o que eu gostaria de ter pago R$300 pra saber
quando comecei (e não sabia por onde procurar). Mas se tá apertado,
segue o conteúdo grátis do perfil — a maior parte eu compartilho aqui mesmo."
```
(Resposta honesta. Sem empurrar. Quem tá apertado é respeitado.)

### Passo 5 — Skill `email-sequence` (backup pra quem compra)
Pós-venda: sequência de 5 emails (Hotmart dispara) pra garantir que o cliente realmente consuma o ebook e, futuramente, vire promotor.
```
/email-sequence produto: ebook R$37, momento: pós-compra,
objetivo: consumo + satisfação + feedback,
5 emails: D+0 entrega, D+3 check-in, D+7 pedir feedback, D+14 segundo produto (se existir), D+30 depoimento/caso
```
**O que espero**: 5 emails escritos em tom de amigo, zero agressividade. Email de feedback (D+7) é crítico pra pipeline 11 (prova social UGC).

### Passo 6 — MCP `whatsapp-mcp` (puxar conversas pra análise)
Depois de 30 DMs, puxar histórico pra entender padrões.
```
mcp call whatsapp-mcp → get_recent_conversations(last_30)
mcp call whatsapp-mcp → extract_objections()
```
**O que espero**: lista das 3 objeções mais comuns (preço, ceticismo, falta de tempo) → virar FAQ + conteúdo orgânico que antecipa essas objeções.

### Passo 7 — Auditoria semanal do funil (toda segunda)
Contar números reais:

| Estágio | Semana atual | Semana anterior | Conversão |
|---------|--------------|-----------------|-----------|
| Views nos posts (top 5) | - | - | - |
| Visitas ao perfil | - | - | -% |
| DMs iniciadas | - | - | -% |
| DMs engajadas (conversa de 3+ msgs) | - | - | -% |
| Cliques no link (Hotmart) | - | - | -% |
| Vendas fechadas | - | - | -% |

**Conversão alvo DM → Venda**: >= 3%.

Se DM → Venda < 1% por 2 semanas: refazer scripts, revisar oferta.

## Outputs esperados
- Pasta `instagram/funil-dm/` com scripts A-E versionados
- Arquivo `instagram/funil-dm/auditoria-semanal.md` atualizado toda segunda
- Lista de objeções comuns → alimenta pipeline 01 (ideias pra conteúdo que antecipa)
- Taxa de conversão DM → Venda documentada

## Métricas de sucesso
- **DM → Venda**: >= 3% (meta ambiciosa), mínimo aceitável 1.5%
- **Tempo de resposta**: < 4h em DMs iniciadas (critical — depois de 24h, conversão cai 70%)
- **Volume de DMs/semana**: crescendo junto com seguidores (meta: 0.5% dos seguidores mandam DM/semana)
- **Ticket médio**: R$37 (único produto agora; quando tiver upsell, subir pra R$60-80)
- **Satisfação pós-compra**: >= 85% NPS positivo (medido por email D+7)

## Quando NÃO usar
- Funil não é pra DM comercial frio (o Weslley NÃO prospecta desconhecido; ele responde quem veio por conta)
- Não é outbound — é inbound conversacional
- Não usar scripts A-E em DM institucional (ex: parceria com marca) — esse tem fluxo próprio (fora de escopo aqui)

## Regras obrigatórias (inegociáveis)

- ❌ NUNCA responder com script copiado sem personalizar (primeiro nome + referência ao que a pessoa disse)
- ❌ NUNCA empurrar venda pra quem perguntou só dúvida de treino
- ❌ NUNCA usar urgência fake ("oferta só hoje", "últimas vagas")
- ❌ NUNCA prometer resultado que não pode garantir
- ✅ SEMPRE oferecer garantia (7 dias devolução) explicitamente
- ✅ SEMPRE respeitar quem diz "não tô podendo agora" — não insistir
- ✅ SEMPRE tratar DM como conversa, não transação
